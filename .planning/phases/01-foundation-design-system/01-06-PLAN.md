<task type="auto">
  <name>Task 2: Keychain store</name>
  <files>src/Core/Credentials/KeychainCredentialStore.swift</files>
  <action>A struct conforming to CredentialStore — the only type calling SecItem APIs. `kSecClassGenericPassword`; `kSecAttrService` from an injectable string defaulting to the bundle id, so tests pass a throwaway one; one item per field with `kSecAttrAccount` of "webhook.url", "webhook.senderKey", "webhook.headerName"; `kSecAttrAccessible` = `kSecAttrAccessibleAfterFirstUnlock` for later background sends.
save: SecItemUpdate, falling back to SecItemAdd on errSecItemNotFound, so re-save overwrites.
load: SecItemCopyMatching per account; nil when url or senderKey is missing. A missing headerName falls back to defaultHeaderName; url and senderKey never get a stand-in.
clear: SecItemDelete per account, errSecItemNotFound treated as success.
Any other status throws CredentialStoreError. No print, NSLog, os_log, or UserDefaults.</action>
  <verify>`grep -rnE 'print\(|NSLog|os_log|UserDefaults' src/Core/Credentials/; test $? -eq 1`; `grep -rl SecItem src/ | grep -v KeychainCredentialStore.swift; test $? -eq 1`; `xcodegen generate`, then `./scripts/smoke.sh` exits 0 — and KeychainCredentialStore.swift appears in the build log's compile lines, proving target membership.</verify>
  <done>Round-trip works, re-save overwrites, no fallback for url or key.</done>
