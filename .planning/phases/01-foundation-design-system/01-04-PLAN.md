<task type="auto">
  <name>Task 1: The smoke gate</name>
  <files>scripts/smoke.sh</files>
  <action>Executable bash (chmod +x), `set -euo pipefail`, cd to repo root from $0, echoing each step:
1. If Signing.xcconfig is absent, print `Signing.xcconfig is missing - copy the .example and set DEVELOPMENT_TEAM and PRODUCT_BUNDLE_IDENTIFIER`, exit 1.
2. `xcodegen generate`.
3. `UDID=$(./scripts/simulator-udid.sh)`, propagating a non-zero exit and message rather than falling back.
4. `xcodebuild test -scheme GrokBotLocator -destination "platform=iOS Simulator,id=$UDID" -derivedDataPath "${SMOKE_DERIVED_DATA:-build/dd-smoke}"`, tee'd to a log beside it. $SMOKE_DERIVED_DATA overrides the path; the shared default reuses a warm cache.
5. Exit 0 only if the log has `** TEST SUCCEEDED **` AND matches `Test run with [1-9][0-9]* test` (Swift Testing's count) — NOT `Executed N tests`, the XCTest line, always 0 here. Else print the tail and exit 1. A scheme missing its test target runs nothing yet succeeds; the count closes it.
Never pass CODE_SIGNING_ALLOWED=NO: it strips entitlements needed on device.
Print no credential values; never echo Signing.xcconfig. Task 2 adds the guard.</action>
  <verify>`./scripts/smoke.sh` exits 0, prints ** TEST SUCCEEDED ** and a non-zero test count.
`mv Signing.xcconfig /tmp/ && ./scripts/smoke.sh; test $? -eq 1`, message names the file; restore.
`SIMULATOR_NAME=NoSuchDevice ./scripts/smoke.sh; test $? -eq 1`.</verify>
  <done>Gate passes clean; fails loudly on missing xcconfig, runtime, or zero tests.</done>
</task>
