The settings state machine — load, validate, persist, report — testable with no Keychain, no
network and no view. Plan 01-10 renders it.
</objective>

<task type="auto">
  <name>Task 1: SettingsModel</name>
  <files>src/Settings/SettingsModel.swift</files>
  <action>`@Observable @MainActor final class SettingsModel`, initialised with a `CredentialStore` — it must never construct KeychainCredentialStore itself. State: urlText, senderKey, headerName (seeded to WebhookCredentials.defaultHeaderName) and a `status` enum with cases idle, saved, error(String).
`load()` populates the fields from the store, leaving them empty when nothing is stored.
`save()` validates before writing: urlText must parse to a URL whose scheme is https; senderKey must be non-empty after trimming; headerName must be non-empty. Each failure sets `status = .error(...)` with a sentence naming the field and the fix — for example "Webhook URL must start with https://" — and writes nothing. Success saves and sets `.saved`.
`clear()` empties the store and the fields.
Never print, log or interpolate a credential value anywhere in the file.</action>
  <verify>`SMOKE_DERIVED_DATA=build/dd-09 ./scripts/smoke.sh` exits 0; `grep -rnE 'print\(|NSLog|os_log' src/Settings/; test $? -eq 1`.</verify>
  <done>Model validates all three fields and reaches storage only through the protocol.</done>
</task>
