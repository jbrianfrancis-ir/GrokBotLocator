<objective>
The type tokens, built so they genuinely scale. A namespace of static `Font`s cannot.
</objective>

<context>
.planning/DESIGN.md is law: body 20, secondary 17, actionLabel 28 semibold, screenTitle 34
bold, Dynamic Type to AX5, nothing under 17pt, no `Font.custom`.
Measured, and the reason this plan exists: a `Font` resolved OUTSIDE a View never sees
`\.dynamicTypeSize`. `Font.system(size: 20)` reads **1.00x at AX5**. `@ScaledMetric` as a
static will not compile under Swift 6, and `@MainActor` to force it through returns 1.00x —
a loud failure turned silent. `UIFontMetrics.scaledFont` static: 1.00x. `@ScaledMetric` as
a **View** property: 2.79x — the only form that works.
</context>

<task type="auto">
  <name>Task 1: DSTextStyle and the font modifier</name>
  <files>src/Core/DesignSystem/DSTypography.swift</files>
  <action>Do NOT write `static let body = Font.system(...)`. It compiles, reads 20pt, and never scales — REQ-12 fails silently and no size-literal grep can see it.
Ship three pieces:
`enum DSTextStyle { case body, secondary, actionLabel, screenTitle }` exposing `size` (20/17/28/34), `weight` (.regular/.regular/.semibold/.bold) and `relativeTo: Font.TextStyle` (.body/.callout/.title2/.largeTitle).
`private struct DSFontModifier: ViewModifier` holding `@ScaledMetric private var scaled: CGFloat`, initialised `_scaled = ScaledMetric(wrappedValue: style.size, relativeTo: style.relativeTo)`, whose body applies `.font(.system(size: scaled, weight: style.weight))`.
`extension View { func dsFont(_ style: DSTextStyle) -> some View { modifier(DSFontModifier(style: style)) } }`.
Call sites use `.dsFont(.body)`. This file is the only place a size literal may appear; none under 17.</action>
  <verify>`grep -nE 'size: *([0-9]|1[0-6])\b' src/Core/DesignSystem/DSTypography.swift; test $? -eq 1`; `grep -q 'func dsFont' src/Core/DesignSystem/DSTypography.swift`; `grep -n 'static let .*Font' src/Core/DesignSystem/DSTypography.swift; test $? -eq 1` (no static Font tokens); smoke.sh does not exist yet: `xcodegen generate && UDID=$(./scripts/simulator-udid.sh) && xcodebuild build -scheme GrokBotLocator -destination "platform=iOS Simulator,id=$UDID" | grep -q 'BUILD SUCCEEDED'`.</verify>
  <done>Tokens reach the View through a modifier; no static Font exists.</done>
