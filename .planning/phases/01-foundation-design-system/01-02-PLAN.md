<task type="auto">
  <name>Task 1: Write scripts/smoke.sh</name>
  <files>scripts/smoke.sh</files>
  <action>Executable bash (chmod +x), `set -euo pipefail`, cd to the repo root resolved from $0. Steps, each echoed:
1. If Signing.xcconfig is absent, print `Signing.xcconfig is missing - copy Signing.xcconfig.example and set DEVELOPMENT_TEAM and PRODUCT_BUNDLE_IDENTIFIER` and exit 1.
2. `xcodegen generate`.
3. Resolve a simulator udid: honour $SIMULATOR_NAME when set, else pick the first available iPhone under an iOS-26 runtime from `xcrun simctl list devices available -j` (parse with a plain shell/python3 filter, no third-party tool). If none, print that no iOS 26 simulator runtime was found and exit 1.
4. `xcodebuild test -scheme GrokBotLocator -destination "platform=iOS Simulator,id=$UDID" -derivedDataPath build/dd-smoke CODE_SIGNING_ALLOWED=NO` with output tee'd to build/smoke.log.
5. Exit 0 only if build/smoke.log contains `** TEST SUCCEEDED **`; otherwise print the tail of the log and exit 1.
Print no credential values and never echo the contents of Signing.xcconfig.</action>
  <verify>`./scripts/smoke.sh` exits 0; `mv Signing.xcconfig /tmp && ./scripts/smoke.sh; echo $?` is non-zero and names the file (restore it afterwards).</verify>
  <done>Script passes on a clean checkout and fails loudly on a missing xcconfig or missing iOS 26 runtime.</done>
</task>
