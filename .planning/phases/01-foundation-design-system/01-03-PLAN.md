<task type="auto">
  <name>Task 1: Type and metric tokens</name>
  <files>src/Core/DesignSystem/DSTypography.swift, src/Core/DesignSystem/DSMetrics.swift</files>
  <action>DSTypography: an enum with static `Font` values declared as `.system(size:weight:design:)` paired with `relativeTo:` text styles (or `@ScaledMetric` helpers) so every one scales to AX5 — `body` 20 regular, `secondary` 17 regular, `actionLabel` 28 semibold, `screenTitle` 34 bold. No font size below 17 may appear in the file.
DSMetrics: an enum of static CGFloats — spacingBase 8, groupGap 24, screenMargin 16, minTapTarget 60, primaryActionHeight 88, cornerRadius 16, primaryActionRadius 28.
Both are plain value namespaces: no state, no view code.</action>
  <verify>`./scripts/smoke.sh` exits 0; reading DSTypography.swift shows exactly the four sizes 20/17/28/34 and no smaller number used as a font size.</verify>
  <done>Both files compile and carry every DESIGN.md token value.</done>
</task>

<task type="auto">
  <name>Task 2: Palette and the machine-checked contrast test</name>
  <files>src/Core/DesignSystem/DSPalette.swift, tests/DesignSystemContrastTests.swift</files>
  <action>DSPalette publishes each token as a value holding explicit light and dark sRGB components (readable by tests) plus a `Color` accessor selecting by ColorScheme. Foreground-on-background pairs, light / dark:
- body: #1A1A1A on #FFFFFF / #F2F2F2 on #000000
- secondary: #4A4A4A on #FFFFFF / #B0B0B0 on #000000
- primaryAction: #FFFFFF on #0A3D91 / #000000 on #7FB3FF
- success: #FFFFFF on #1B5E20 / #000000 on #7BE38A
- failure: #FFFFFF on #8E0000 / #000000 on #FF9A94
- pending: #FFFFFF on #6B4A00 / #000000 on #FFC95C
DesignSystemContrastTests: a test-local WCAG 2.x relative-luminance and contrast-ratio implementation; one `@Test` iterating every pair in both appearances with `#expect` — >= 7.0 for body, primaryAction, success, failure and pending text; >= 4.5 for secondary. Put the measured ratio and the pair name in the failure message. Swift Testing, not XCTest.</action>
  <verify>`./scripts/smoke.sh` exits 0 with the contrast test passing; deliberately darkening one foreground makes it fail with the ratio named (revert afterwards).</verify>
  <done>Every palette pair is proven against DESIGN.md's floors in both appearances by a test that can actually fail.</done>
</task>
