<objective>
The type tokens, built so they genuinely scale. Static `Font`s cannot.
</objective>

<context>
From 01-02: simulator-udid.sh, the @main skeleton (so the app links), a hosted test bundle.
DESIGN.md is law: body 20, secondary 17, actionLabel 28 semibold, screenTitle 34 bold,
Dynamic Type to AX5, nothing under 17pt, no `Font.custom`.
Measured, and why this plan exists: a `Font` resolved OUTSIDE a View never sees
`\.dynamicTypeSize`, so it never scales. `Font.system(size: 20)` reads 1.00x at AX5;
`@ScaledMetric` as a static will not compile under Swift 6, and `@MainActor` to force it
reads 1.00x — a loud failure turned silent. As a **View** property it reads 2.79x: the only
form that works.
</context>
