<task type="auto">
  <name>Task 1: SettingsModel</name>
  <files>src/Settings/SettingsModel.swift</files>
  <action>`@Observable @MainActor final class SettingsModel`, initialised with a `CredentialStore` — it never constructs KeychainCredentialStore itself. State: urlText, senderKey, headerName (seeded to WebhookCredentials.defaultHeaderName), `hasStoredKey: Bool` (false initially — 01-11 renders its saved-indicator from this), and a `status` enum with cases idle, saved, error(String).
`load()` populates url and headerName from the store and sets `hasStoredKey` true when a key exists; it must NOT assign the stored key to the senderKey field (D-10 — the key is never re-rendered). Fields stay empty and hasStoredKey false when nothing is stored. Saving with an untouched senderKey while hasStoredKey is true keeps the existing key, not clears it.
`save()` validates before writing: urlText must parse to an https URL; senderKey non-empty after trimming; headerName non-empty. Each failure sets `status = .error(...)` with a sentence naming the field and the fix — for example "Webhook URL must start with https://" — and writes nothing. Success saves and sets `.saved`.
`clear()` empties the store and fields.
Never print, log or interpolate a credential value.</action>
  <verify>`./scripts/smoke.sh` exits 0; `grep -rnE 'print\(|NSLog|os_log' src/Settings/; test $? -eq 1`.</verify>
  <done>Model validates all three fields and reaches storage only through the protocol.</done>
</task>
