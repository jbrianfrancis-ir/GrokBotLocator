<task type="auto">
  <name>Task 1: SettingsModel</name>
  <files>src/Settings/SettingsModel.swift</files>
  <action>`@Observable @MainActor final class SettingsModel`, init with a `CredentialStore` — never constructs KeychainCredentialStore itself. State: urlText, senderKey, headerName (seeded to WebhookCredentials.defaultHeaderName), `hasStoredKey: Bool` (false initially — 01-12 renders its saved-indicator from it), and `status`: idle, saved, error(String).
`load()` fills url and headerName from the store and sets `hasStoredKey` when a key exists; it must NOT assign the stored key to the senderKey field (D-10). Fields stay empty and hasStoredKey false when nothing is stored. Saving with an untouched senderKey while hasStoredKey is true re-reads the stored key via `store.load()` and writes it back — the model never holds the key (D-10), so this is the only way not to blank it.
`save()` validates first: urlText parses to an https URL; senderKey non-empty after trimming; headerName non-empty. Each failure sets `status = .error(...)` naming the field and fix (e.g. "Webhook URL must start with https://") and writes nothing. Success saves and sets `.saved`.
`clear()` empties store and fields AND sets hasStoredKey false — else 01-12 still shows "key saved".
Never print, log or interpolate a credential.</action>
  <verify>`./scripts/smoke.sh` exits 0; `grep -rnE 'print\(|NSLog|os_log' src/Settings/; test $? -eq 1`.</verify>
  <done>Model validates all three fields and reaches storage only through the protocol.</done>
</task>
