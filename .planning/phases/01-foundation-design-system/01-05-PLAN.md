  <action>Swift Testing, never XCTest, as `@Suite struct DesignSystemContrastTests { … }` — a bare `@Test` emits no Suite line, leaving the verify nothing to assert. One `@Test` iterating every pair in both appearances: `#expect` ratio >= 7.0 for body, primaryAction, success, failure, pending; >= 4.5 for secondary. The failure message names the pair, the appearance, and the ratio to one decimal.</action>
  <verify>`xcodegen generate` exits 0; then `./scripts/smoke.sh` exits 0 AND `grep -qE 'Suite DesignSystemContrastTests passed'` on its log. NOT the bare name — the compile line carries it whether or not a test ran.

  <done>All twelve pair-appearance combinations are machine-verified against DESIGN.md's floors.</done>
