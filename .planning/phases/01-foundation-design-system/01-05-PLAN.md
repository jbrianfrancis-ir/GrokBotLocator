<task type="auto">
  <name>Task 2: Keychain implementation</name>
  <files>src/Core/Credentials/KeychainCredentialStore.swift</files>
  <action>A struct conforming to CredentialStore — the only type in the app calling SecItem APIs. `kSecClassGenericPassword`; `kSecAttrService` from an injectable service string defaulting to the bundle id, so tests can pass a throwaway one; one item per field with `kSecAttrAccount` of "webhook.url", "webhook.senderKey", "webhook.headerName"; `kSecAttrAccessible` = `kSecAttrAccessibleAfterFirstUnlock` so later phases can send from the background.
save: SecItemUpdate, falling back to SecItemAdd on errSecItemNotFound, so re-saving overwrites.
load: SecItemCopyMatching per account; nil when url or senderKey is missing. A missing headerName falls back to defaultHeaderName; url and senderKey never get a stand-in.
clear: SecItemDelete per account, errSecItemNotFound treated as success.
Any other status throws CredentialStoreError. No print, NSLog, os_log, or UserDefaults in the file.</action>
  <verify>`grep -rnE 'print\(|NSLog|os_log|UserDefaults' src/Core/Credentials/; test $? -eq 1`; `grep -rl SecItem src/ | grep -v KeychainCredentialStore.swift; test $? -eq 1`; `UDID=$(./scripts/simulator-udid.sh) && xcodebuild build -scheme GrokBotLocator -destination "platform=iOS Simulator,id=$UDID" -derivedDataPath build/dd-05 | grep -q 'BUILD SUCCEEDED'`.</verify>
  <done>Round-trip storage works, re-save overwrites, no fallback exists for url or key.</done>
</task>
