  <name>Task 1: QueueDrainCoordinator</name>
  <files>src/App/QueueDrainCoordinator.swift</files>
  <action>`@MainActor final class QueueDrainCoordinator` with `init(store: any PingQueueStoring, drain: PingQueueDrain, model: PingModel, connectivity: any ConnectivityObserving, now: @Sendable () -> Date)`, plus `private var hasHydrated = false` and `private var connectivityTask: Task<Void, Never>?`.
- `func start() async` — idempotent: `hydrate()`, then `await drainForeground()`, then start the connectivity task if `connectivityTask` is nil.
- `private func hydrate() async` — returns immediately when `hasHydrated`; otherwise sets it and `try? await store.load()`, mapping each `QueuedPing` to a `PingDeliveryUpdate` (id; `timestamp: payload.capturedAt`; coordinates and label from the payload; `.failed` with `permanentFailure` when that is set, else `.queued` with the standing sentence "Waiting to send. It will go out at the next opportunity."). A standing sentence deliberately, not the original one: a three-day-old "The webhook is unavailable (HTTP 503)" is no longer true, and this is the row a user sees after a relaunch. Take only the LAST `PingHistoryLog.capacity` entries (the queue holds up to 200, the log shows 50) and hand them to `model.apply(updates, announcing: false)` OLDEST FIRST so the log ends up newest-first. `announcing: false` is load-bearing, not tidiness: `PingAttemptFeedback.spoken` renders anything that is not `.sent` as "Ping failed. …", so announcing here would tell a user at launch that a ping they never tapped had failed. Say in a comment that the cap bounds what is DISPLAYED and never what is delivered: an entry past it stays on file and still drains, so SC-02 is unaffected by the display bound.
- `func drainForeground() async` — `await drain.drain(before: now().addingTimeInterval(25), surfacingFailures: true)`; `model.apply(report.updates, announcing: true)`; when `report.notice` is non-nil, `model.show(notice: report.notice)` — the entry point 03-07 adds. `PingModel.guidance` is `private(set)` and stays that way; do not reach for it directly.
- `func drainBackground() async` — the same with `surfacingFailures: false` and a 20-second budget: a `BGAppRefreshTask` gets seconds, and the transport's own 30-second resource bound caps one attempt, not the whole drain.
- `private func startObservingConnectivity()` — one `Task` iterating `connectivity.onlineEdges()`, calling `await drainForeground()` per edge, stored in `connectivityTask`; `func stop()` cancels it.
Nothing here prints, logs, names a coordinate, or reads a clock directly.</action>
