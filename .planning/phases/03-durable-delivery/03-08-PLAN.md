  <name>Task 1: DurablePingSink</name>
  <files>src/Queue/DurablePingSink.swift</files>
  <action>`struct DurablePingSink: PendingPingSink` with `let store: any PingQueueStoring`, `let policy: PingRetryPolicy`, and `let now: @Sendable () -> Date` (injected, so the entry's timestamps are testable and the type reads no clock of its own).

`enqueue(_ payload:reason:) async -> PingEnqueueOutcome`:
- mint `let id = UUID()` and `let stamp = now()`;
- build `QueuedPing(id: id, payload: payload, firstAttemptAt: stamp, attemptsMade: 1, nextAttemptAt: policy.nextAttemptDate(afterAttempts: 1, now: stamp), permanentFailure: nil)`. `attemptsMade: 1` because the live attempt that just failed IS the first attempt — starting at 0 would retry immediately and re-fail on the same dead connection;
- `try await store.append(entry)` then return `.queued(id: id)` — the id is returned only after the write returned, so nothing is called pending before the disk has it;
- `catch PingQueueError.full` → `.notQueued(reason: "The offline queue is full (200 pings waiting), so this ping was not saved. Send or clear the waiting pings, then tap I'm here again.")`;
- `catch PingQueueError.unreadable` → `.notQueued(reason: "The offline queue file could not be read and has been set aside, so this ping was not saved. Tap I'm here again.")`;
- `catch` anything else → `.notQueued(reason: "This ping could not be saved to the offline queue, so it was not kept. Check that the device has free storage, then tap I'm here again.")`. NEVER interpolate the caught error, the URL, the key, or a coordinate into any of these sentences.
Each sentence says what happened and what to do next (DESIGN.md), and none is a bare status word.</action>
  <verify>`SMOKE_DERIVED_DATA=build/dd-03-08 ./scripts/smoke.sh` exits 0, and `grep -nE 'print\(|NSLog|os_log|\\\(error|credentials|senderKey|latitude|longitude' src/Queue/DurablePingSink.swift` finds nothing (exit 1).</verify>
  <falsify>Change the generic catch to `.notQueued(reason: "Could not save: \(error)")`: the `\(error` pattern matches and the grep exits 0. Revert.</falsify>
  <done>The sink writes before it promises, and every refusal is a safe finished sentence.</done>
