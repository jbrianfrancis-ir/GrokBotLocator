<task type="auto">
  <name>Task 1: ConnectivityEdge and the NWPathMonitor wrapper</name>
  <files>src/Queue/Connectivity.swift</files>
  <action>Three declarations:
- `struct ConnectivityEdge: Sendable, Equatable` — one stored `private var lastSatisfied: Bool?` starting `nil`, and `mutating func observe(satisfied: Bool) -> Bool` returning true ONLY when the previous value was `false` and the new one is `true`. `nil → true` returns false (documented: the first reading is the state the app launched in, and launch already drains). `true → true`, `false → false` and `true → false` all return false.
- `protocol ConnectivityObserving: Sendable { func onlineEdges() -> AsyncStream<Void> }` — yields exactly once per rising edge. A protocol so the drain coordinator (03-10) is testable with a stream a test drives by hand.
- `final class NWPathMonitorConnectivity: ConnectivityObserving, @unchecked Sendable` — the only type in the app that imports `Network`. `onlineEdges()` returns an `AsyncStream<Void>` whose builder creates an `NWPathMonitor`, starts it on a private `DispatchQueue(label: "connectivity")`, and in `pathUpdateHandler` feeds `path.status == .satisfied` through a lock-guarded `ConnectivityEdge`, calling `continuation.yield()` only when `observe(satisfied:)` returns true. Set `continuation.onTermination` to `monitor.cancel()` so the monitor dies with the stream. Lock-guard the `ConnectivityEdge`, not `nonisolated(unsafe)`: `pathUpdateHandler` runs on the monitor's queue while `onTermination` runs elsewhere (see .planning/LEARNINGS.md on the nonisolated-async fake that hung phase 02's suite).
No `Task.sleep`, no timer, no retry logic here — this file reports transitions and nothing else.</action>
