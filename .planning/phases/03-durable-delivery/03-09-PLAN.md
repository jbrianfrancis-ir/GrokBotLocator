<task type="auto">
  <name>Task 1: PingDrainReport and the PingQueueDrain actor</name>
  <files>src/Queue/PingQueueDrain.swift</files>
  <action>`struct PingDrainReport: Sendable, Equatable { let updates: [PingDeliveryUpdate]; let notice: String? }` — `notice` is a finished sentence for a condition that stopped the drain rather than a per-ping outcome (no credentials, unreadable file), and is nil on an ordinary drain.

`actor PingQueueDrain` — an actor so two triggers (a connectivity edge and a foreground, say) cannot interleave a read-modify-write of the file. `init(store: any PingQueueStoring, credentials: any CredentialStore, transport: any PingTransport, policy: PingRetryPolicy, now: @Sendable () -> Date)`.

`func drain(before deadline: Date, surfacingFailures: Bool) async -> PingDrainReport`:
1. `store.load()` — a `PingQueueError.unreadable` returns `PingDrainReport(updates: [], notice: "Some pings waiting to be sent could not be read and have been set aside. They cannot be delivered.")`; any other throw returns an empty report with a storage sentence. Nothing is written.
2. credentials: nil or a throw returns `PingDrainReport(updates: [], notice: "Add your webhook URL and sender key in Settings — \(queue.count) ping(s) are waiting to be sent.")` and writes nothing. An unreadable key must never empty the queue.
3. Walk the entries OLDEST FIRST (the array is append-ordered, so front to back), collecting updates. For each:
   - `now() >= deadline` → stop the walk; every remaining entry stays exactly as it is.
   - `entry.permanentFailure != nil` (marked during an earlier, non-surfacing drain) → emit a `.failed` update carrying that sentence; drop the entry from the surviving array only when `surfacingFailures`.
   - `policy.hasGivenUp(firstAttemptAt: entry.firstAttemptAt, now: now())` → set `permanentFailure = PingRetryPolicy.gaveUpReason`, emit a `.failed` update with it, drop only when `surfacingFailures`. Do not send.
   - `entry.nextAttemptAt > now()` → skip entirely; no send, no update, no change.
   - otherwise send: `transport.send(entry.payload, using: credentials)` classified by `PingClassifier`, a throw classified by `disposition(forTransportError:)`. `.sent` → emit a `.sent` update (reason nil) and drop the entry. `.permanentFailure(let r)` → set `permanentFailure = r`, emit a `.failed` update with it, drop only when `surfacingFailures`. `.retryable` → `attemptsMade += 1`, `nextAttemptAt = policy.nextAttemptDate(afterAttempts: attemptsMade, now: now())`, keep the entry, emit NO update (the row already reads Queued and nothing about it has changed for the user).
   - after each entry, `try? await store.replace(with: surviving)` — after each, not once at the end, so a process killed mid-drain cannot re-send a ping it already delivered.
4. Build each `PingDeliveryUpdate` from the entry: `id`, `timestamp: entry.payload.capturedAt`, `latitude`/`longitude`/`label` from the payload, plus the outcome and reason. Return the collected updates with `notice: nil`.
Nothing in this file prints, logs, or interpolates a credential or a coordinate.</action>
