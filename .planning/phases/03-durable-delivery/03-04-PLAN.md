<objective>
Give a queued ping an identity and carry it up the pipeline, so a "Queued" row on screen and an
entry in the queue file are the same ping and one can later update the other.
</objective>

`UnqueuedPingSink.enqueue` still returns `.notQueued(reason: reason)` — unchanged.

In `send(label:)`, the retryable arm becomes: `case .queued(let id)` keeps the `.retryable` disposition and remembers `id` in a local `queuedID`; `case .notQueued(let why)` downgrades to `.permanentFailure(reason: why)` and leaves `queuedID` nil, exactly as today. Pass `queuedID:` into the returned `PingAttempt`. Every non-retryable path returns `queuedID: nil` — a delivered or permanently rejected ping is held by nothing.
