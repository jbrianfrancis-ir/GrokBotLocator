explains what the current authorization level does not allow. All pure: no CLLocationManager
here, so everything above it is testable without a device.

<task type="auto">
  <name>Task 1: LocationFix, LocationFixError, LocationFixProvider, authorization notice</name>
  <files>src/Core/Location/LocationFix.swift</files>
  <action>`import CoreLocation` (for `CLAuthorizationStatus` only — no manager in this file). Declare, all `Sendable`:
- `struct LocationFix: Sendable, Equatable { let latitude: Double; let longitude: Double; let accuracyMetres: Double; let timestamp: Date }` plus `func payload(label: String) -> PingPayload` mapping straight across.
- `static func validated(latitude: Double, longitude: Double, horizontalAccuracy: Double, timestamp: Date) throws -> LocationFix` on `LocationFix` — the ONLY constructor 02-06 is allowed to use. It throws `LocationFixError.invalidAccuracy` when `horizontalAccuracy < 0` (CoreLocation's documented signal that the measurement is invalid) and otherwise returns the fix. Keeping the guard here rather than inside the CoreLocation adapter is what makes it testable without a device; see backstop_truths.
- `enum LocationFixError: Error, Equatable, Sendable` with cases `notAuthorized`, `deniedGlobally`, `unavailable`, `timedOut`, `invalidAccuracy`, and a computed `var reason: String` giving each a finished sentence that says what happened and what to do next (e.g. `.timedOut` → "Could not get a location fix in time. Move somewhere with a clearer view of the sky, then tap again.").
- `protocol LocationFixProvider: Sendable { func currentFix() async throws -> LocationFix; func authorizationNotice() async -> String? }`.
- `enum LocationAuthorizationNotice { static func notice(for status: CLAuthorizationStatus) -> String? }`: `.notDetermined` and `.authorizedAlways` → nil; `.authorizedWhenInUse` → "Manual pings work now. Automatic pings while the app is closed need Always — turn on a trigger to be asked for it."; `.denied` → a sentence naming Settings ▸ Privacy & Security ▸ Location Services ▸ GrokBotLocator and "While Using the App"; `.restricted` → a sentence saying location is restricted on this device and manual pings cannot include a position. Default arm → nil.
Never print, log, or interpolate a coordinate into a string in this file.</action>
