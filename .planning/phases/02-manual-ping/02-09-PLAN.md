State: `var label: String` with `didSet { labelStore.save(label) }`, seeded in `init` from `labelStore.loadLabel()`. Note what that seeding actually does: `@Observable` rewrites `label` into a computed property, so the init assignment goes through the generated setter and DOES fire `didSet` — the first launch writes the loaded value straight back to the store. That is one redundant same-value write per launch and nothing more; accept it and say so in a one-line comment rather than reaching for a separate backing property. `private(set) var isInFlight = false`; `private(set) var log = PingHistoryLog()`; `private(set) var guidance: String?`; `private(set) var authorizationNotice: String?`; `private(set) var lastAnnouncement: String?`.
`func refreshAuthorizationNotice() async { authorizationNotice = await fixes.authorizationNotice() }` — the view calls it from `.task`.
`func ping() async`:
- `guard !isInFlight else { return }`; set `isInFlight = true`, `defer { isInFlight = false }`; clear `guidance`;
- `let attempt = await sender.send(label: label)`;
- map the disposition: `.sent` → outcome `.sent`, reason nil, announcement "Ping sent."; `.permanentFailure(let r)` and `.retryable(let r)` → outcome `.failed`, reason `r`, announcement "Ping failed. " + r. Add a one-line comment that phase 03 (REQ-05) changes the `.retryable` arm to `.queued` once the durable queue exists;
- if `attempt.fix` is non-nil, `log.record(PingHistoryEntry(timestamp: fix.timestamp, latitude: fix.latitude, longitude: fix.longitude, label: label, outcome: outcome, reason: reason))`. If it is nil there are no coordinates to show, so record nothing and set `guidance` to the reason instead;
- after a ping, `await refreshAuthorizationNotice()` — a first ping is also when the prompt is answered, so the notice can only be right afterwards.
Never print, log, or interpolate a credential. Never touch a `CLLocationManager`.</action>
