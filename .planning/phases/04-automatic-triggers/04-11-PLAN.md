wake, and decides — using the gate, not the OS — whether each wake becomes a ping.

  <name>Task 2: the three handlers, drained first and serialized</name>
  <files>src/Triggers/TriggerCoordinator.swift</files>
  <action>Add `private var chain: Task<Void, Never>?` and `private func serialized(_ body: @escaping @Sendable () async -> Void)` that captures the CURRENT `chain` into a local and immediately assigns a new `Task { await previous?.value; await body() }` — the assignment happens before any suspension, so two callbacks arriving at once queue rather than interleave. Comment names LEARNINGS' actor-reentrancy entry and says plainly what interleaves without it: two wakes both read the old `reference`, both clear the 500 m gate, and the reference ends up at whichever finished last.

Three handlers, each wrapped in `serialized`:
- `func handleSignificantChange(_ report: SignificantChangeReport) async` — (1) `await drain()`, FIRST and unconditional, before any check at all: the wake is a drain opportunity whether or not it becomes a ping, and this is REQ-05's carried fourth opportunity; (2) `guard settings.significantChangeEnabled else { return }`; (3) `guard let fix = report.locationFix() else { return }`; (4) `let coordinate = TriggerCoordinate(fix: fix)`; (5) if `reference` is nil, try `reference = await geofence.currentCentre()` — the cold-relaunch rehydration, which is why the app keeps no coordinate file of its own; (6) `guard DisplacementGate.shouldPing(from: reference, to: coordinate) else { return }`; (7) `await pingAndAdvance(fix: fix, coordinate: coordinate, trigger: .significantChange)`.
- `func handleVisit(_ report: VisitReport) async` — `await drain()` first; then `guard settings.visitsEnabled`, `guard report.isArrival` (a departure produces no ping, REQ-07), `guard let fix = report.locationFix()`, then `pingAndAdvance(..., trigger: .arrival)`. No displacement gate here: REQ-07 is about lingering somewhere, not about distance.
- `func handleGeofenceExit(at date: Date) async` — `await drain()` first; then `guard settings.geofenceEnabled`; take a one-shot fix with `try? await fixes.currentFix()` because `CLMonitor.Event` carries no coordinate (RESEARCH Q2 lists its fields); `guard let fix`; then `pingAndAdvance(..., trigger: .geofenceExit)`.

`private func pingAndAdvance(fix:coordinate:trigger:) async` — `await pinger.ping(fix:trigger:)`; only when the result is `.pinged` set `reference = coordinate` and, if `settings.geofenceEnabled`, `await geofence.register(at: coordinate)`. A `.rateLimited` or `.noCredentialsOrFix` result advances nothing: the reference means "where the last ping was", and no ping happened.</action>
