  <name>Task 2: MapKitTriggerLabelProvider</name>
  <files>src/Triggers/MapKitTriggerLabelProvider.swift</files>
  <action>`import CoreLocation`, `import Foundation`, `import MapKit`. This is the ONE file permitted to import MapKit (D-15, ARCHITECTURE Forbidden).

`struct MapKitTriggerLabelProvider: TriggerLabelProviding`:
- `static let budget: Duration = .seconds(3)` and `let budget: Duration`, with `init(budget: Duration = MapKitTriggerLabelProvider.budget)`. State the bound in the header: a label attempt may hold the ping path for at most 3 seconds. It is a chosen bound, not a derived one — REQUIREMENTS.md:34 requires only that geocoding never delays delivery, and 3 s is generous for decoration while leaving an automatic ping on a background wake almost all of the system time it is given.
- `func label(for coordinate: TriggerCoordinate) async -> String`:
  1. `guard let request = MKReverseGeocodingRequest(location: CLLocation(latitude: coordinate.latitude, longitude: coordinate.longitude)) else { return "" }` — the initializer is failable (RESEARCH Q1) and a nil is a normal empty label, never a crash.
  2. Race the request against the budget with `withTaskGroup(of: String?.self)`: one child returns `(try? await request.mapItems)?.first?.addressRepresentations?.cityName`, the other does `try? await Task.sleep(for: budget)` then returns nil. Take the FIRST child to finish — `let winner = await group.next() ?? nil` — then `group.cancelAll()` and `request.cancel()` on the way out so the loser does not keep running. Do not force-unwrap `group.next()`.
  3. `return normalisedTriggerLabel(winner ?? "")`.
- Every failure path lands on "": a nil init, a thrown error swallowed by `try?`, an empty `mapItems`, a nil `cityName`, a whitespace-only name, and the budget expiring. There is no other outcome and the function cannot throw.
- Route the locality through `mapItem.addressRepresentations?.cityName` ONLY. Do NOT use `mapItem.placemark` — `MKPlacemark` is deprecated at iOS 26.0 with the message to use `MKMapItem`'s own properties (RESEARCH Q1).
- Use no other MapKit type: no `MKMapView`, no annotation, no region, no tile. D-15 authorized reverse geocoding only and 04-01's guard enforces it.
- Header comment records, as prose: REQUIREMENTS.md:34's statement that reverse geocoding sends a coordinate to Apple's geocoding service — inherent to the feature, not "storing or logging" under the Forbidden entry, but real egress and written down here so it is a known property at the call site. Nothing in this file writes, logs or prints a coordinate.</action>
