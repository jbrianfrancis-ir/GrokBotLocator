  <files>src/Ping/PingModel.swift, src/App/GrokBotLocatorApp.swift</files>
  <action>In `PingModel`: add `private let rateLimiter: any PingRateLimiting` and `private let now: @Sendable () -> Date` as init parameters with NO default values — LEARNINGS records that a default is how a bounded dependency got quietly replaced by an unbounded one, and the composition root must name both explicitly.
In `ping()`, immediately after `guidance = nil` and before `await sender.send(label:)`, insert:
```
switch await rateLimiter.claim(at: now()) {
case .allowed: break
case .tooSoon(_, let reason):
    guidance = reason
    attemptSequence += 1
    lastAttempt = PingAttemptFeedback(sequence: attemptSequence, outcome: .failed, reason: reason)
    return
}
```
The `defer { isInFlight = false }` already installed above covers the early return. Comment that this is the same shape as the no-fix branch further down — nothing was sent, so nothing is logged, and the user is told on screen and in speech rather than left with a button that did nothing. Note explicitly that the claim happens BEFORE the send, so a refused tap does not consume a slot twice, and that this is the one gate REQ-09/SC-04 counts both kinds of ping through.
Where `ping()` records its `PingHistoryEntry`, pass `trigger: .manual`.
In `GrokBotLocatorApp.init()`: construct `let rateLimiter = PingRateLimiter()` as a local beside the other dependencies and pass it plus `now: { Date() }` into `PingModel(...)`. Nothing else in that file changes in this plan.</action>
