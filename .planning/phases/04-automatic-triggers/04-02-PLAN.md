  <name>Task 1: PingRateLimiter</name>
  <files>src/Core/Ping/PingRateLimiter.swift</files>
  <action>Three declarations in one file, `import Foundation` only:

`enum RateLimitDecision: Sendable, Equatable` — `case allowed` and `case tooSoon(retryAfter: TimeInterval, reason: String)`.

`protocol PingRateLimiting: Sendable` — `func claim(at now: Date) async -> RateLimitDecision` and `func setMinimumInterval(_ seconds: TimeInterval) async`. A protocol so PingModel and AutomaticPinger depend on the seam, not the actor (ARCHITECTURE: protocol-backed and injected).

`actor PingRateLimiter: PingRateLimiting` with `static let hardFloor: TimeInterval = 15` and `static let defaultInterval: TimeInterval = 60`:
- `private var interval: TimeInterval` and `private var lastAllowed: Date?`.
- `init(minimumInterval: TimeInterval = PingRateLimiter.defaultInterval, lastAllowed: Date? = nil)` — the interval runs through the same clamp as the setter.
- `func setMinimumInterval(_ seconds: TimeInterval)` — stores `max(seconds, Self.hardFloor)`. A NaN or negative input also lands on 15. Clamping, never rejecting: REQ-09 says the interval "cannot be set below 15 s", and a silently ignored setter would leave Settings showing a value the limiter is not using.
- `func claim(at now: Date) -> RateLimitDecision` — if `lastAllowed` is nil, or `now.timeIntervalSince(lastAllowed!) >= interval`, set `lastAllowed = now` and return `.allowed`; otherwise return `.tooSoon` with `retryAfter = interval - now.timeIntervalSince(lastAllowed!)` and a finished sentence, e.g. "Too soon — pings are spaced at least \(Int(interval)) seconds apart. Try again in \(Int(ceil(retryAfter))) seconds." Body ends in a full stop and never renders a bare number alone.
- **There must be no `await` anywhere inside `claim` or `setMinimumInterval`.** Write that as a comment naming the reason (LEARNINGS' actor-reentrancy entry): the read-modify-write is atomic only because the actor is never suspended mid-function. A future edit that introduces an `await` here reopens the hole.
Document in the file header that BOTH backstop decisions in this plan's `backstop_truths` are open choices this phase's requirements do not settle, so a later reader does not mistake either for a derived rule.
No `Date()`, no `Task.sleep`, no `Timer`, no `DispatchQueue` anywhere in the file.</action>

THEN the absence: `grep -nE 'Date\(\)|Task\.sleep|Timer|DispatchQueue|await ' src/Core/Ping/PingRateLimiter.swift` finds nothing (exit 1). Then `SMOKE_DERIVED_DATA=build/dd-04-02 ./scripts/smoke.sh` exits 0.</verify>
  <falsify>Insert `await Task.yield()` as the first line of `claim(at:)`: the grep matches `await ` and exits 0. Revert.</falsify>
  <done>A clamped, clock-free gate whose critical section cannot suspend.</done>
